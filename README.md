# CrickSync 🏏

CrickSync is a mobile-first cricket scheduling and team management app.

## Goal

Help cricket players and captains keep every match commitment in one place, avoid schedule conflicts, and manage teams.

## Platforms

- Android
- iOS

## Repository

- `apps/mobile` — React Native + Expo + TypeScript
- `apps/api` — Node.js + TypeScript API
- `packages/shared` — shared types and validation
- `docs` — product and technical documentation

## MVP

1. Authentication and onboarding
2. Player/Captain profiles
3. Player calendar
4. Captain teams
5. Match creation
6. Player invitations
7. Accept/reject workflow
8. Match conflict detection
9. Match reminders
10. Match venue/location
11. Basic team and direct chat

Future phases will add tournaments, statistics, cricket reels, payments, subscriptions, ads, and AI features.

## Development principle

Build and verify one milestone at a time. Do not add future-phase features to the MVP until the core scheduling workflow is stable.
